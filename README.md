# SSCP Angular Keyframe GUI
This program was developed as internal tooling for Team Parakeet Blue's Project Soundscape. Due to the nature of the Soundscape Experience, it is often preferential to control virtual source locations in terms of their speed, and not their location. This is especially true for music, in cases where rotational speed should match the lyrics or the song.

To run this program, you will need to install VLC Media Player, and also run `pip install python-vlc`. The program has been tested on Linux and Windows, on Python3.10 and 3.12.
